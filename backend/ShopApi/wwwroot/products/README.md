# รูปสินค้า

วางไฟล์รูปในโฟลเดอร์นี้ ตั้งชื่อตาม `Products.Code` **ตัวพิมพ์ใหญ่ นามสกุล `.jpg`**
เสิร์ฟผ่าน `app.UseStaticFiles()` ที่ `GET /products/<code>.jpg`

## แหล่งรูป license ฟรี ใช้เชิงพาณิชย์ได้

- https://www.pexels.com — มีรูปของกินของใช้เยอะ เหมาะกับโจทย์นี้ที่สุด
- https://unsplash.com
- https://pixabay.com

## ข้อแนะนำ

- ย่อให้เหลือราว **600×600 px** และไม่เกินไฟล์ละ ~150 KB ก่อน commit
  (รูปจาก stock site เป็น 4000px ไฟล์ละ 3-5 MB จะทำให้ repo บวมโดยไม่จำเป็น)
- ครอปเป็นสี่เหลี่ยมจัตุรัส grid หน้าสินค้าจะได้เรียงสวย ไม่ต้องมาแก้ CSS ทีหลัง
- ชื่อไฟล์ **case-sensitive** บน Linux — ต้องเป็น `P001.jpg` ตัวใหญ่ ไม่ใช่ `p001.jpg`

## เช็คว่าใช้ได้

```bash
cd backend/ShopApi && dotnet run
# แล้วเปิด http://localhost:5223/products/P001.jpg
```
